# AWS Certified Cloud Practitioner — Interactive CBT

An interactive, adaptive computer-based training course for the **AWS Certified Cloud Practitioner (CLF-C02)** certification, built by Interstitium Labs.

**Live:**
- https://interstitiumlabs.dev/bootcamps/aws-clf/
- https://learn.interstitiumlabs.dev/bootcamps/aws-clf/
- https://enmanueldmejia.com/bootcamps/aws-clf/

## What's inside

- **36 adaptive scored scenarios** across 6 domains, with a drill queue that targets your weakest areas first
- **6 structured lessons** (concepts, worked examples, common pitfalls)
- **10 guided hands-on labs** + **6 simulated terminal missions** — everything runs in your browser, nothing leaves your device
- **4 multi-step troubleshooting simulations**
- **Timed exam-prep mode**: 30 items in 45 minutes
- **Chat practice companion** for mock-assessment drills

## How it works

Open `index.html` in any browser — self-contained static site, zero dependencies. Progress and mastery are tracked locally in your browser (localStorage).

**Independent practice material.** Not affiliated with, endorsed by, or sponsored by Amazon Web Services. Confers no certificate. All scenarios are original; no exam content is reproduced.
